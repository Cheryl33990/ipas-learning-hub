## 下一個最小改善提案：先做支持範圍標註版評估 v2

**建議、尚未採用**：先只改善評估參考的可解釋性，建立獨立 v2 的「片段支持範圍」標註；不改檢索排序、模型、切塊、查詢與 k。理由是目前同時存在真正排序落後、相關頁未列入、同頁錯塊仍算命中，以及概念頁不足支持答案。此時只追原頁命中數，可能把找到有用內容判為失敗，或把術語出現當完整解題能力。
