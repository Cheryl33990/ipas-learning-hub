# 專案簡述

iPAS AI 應用規劃師備考輔助：讓每一道題目都能找到教材出處，之後再提供選項解析。本檔是範圍與成功條件的單一來源。

## 原始描述
- 我想改善的困擾／期待（使用者原話，2026-11-16）：「我看到題目不知道要怎麼選，拿關鍵字去 CTRL F 查教材，還需要自己判定是哪邊錯。所以我會希望有可以知道出處，還有結合 web search 或是公開確認的資料，讓我能更加系統化學習。」
- 最初提出的方案（尚未成為已確認方案）：模擬考古題系統；教材向量化的語意搜尋知識庫，未來串接 LLM 回答問題。
- 長期期待：「供應給所有需要的備考人」。
- 最近一次具體情境：準備考試時遇到不會選的題目，用關鍵字逐一搜尋教材 PDF，找到後自行比對各選項。

### 原因假設（未驗證）
- H-01：關鍵字搜尋失敗的主因是題目用詞與教材用詞不同。
- H-02：向量檢索比關鍵字搜尋更容易找到題目的依據段落。
- H-03：有一部分題目的依據不在教材內，需要外部資料。
- H-04：其他備考人有相同困擾。

### 卡點拆解
| 類型 | 描述 | 可能的解法 |
|---|---|---|
| A 找不到 | 用詞不同或命中太多處 | 檢索 |
| B 找到但要自己推理 | 教材只講概念，選項對錯要自行比對 | LLM 解析 |
| C 教材沒有 | 依據不在學習指引內 | 外部資料 |

三類各佔多少目前未知，這個比例決定第二輪先做什麼。

## 尚未知與下一步探索
- 最影響決策的未知：
  1. A／B／C 三類題目的比例。
  2. 公告試題是否附官方答案：所選試題已確認附有（2026-11-16 開檔），其他梯次未查。
  3. 教材與試題能否公開再散布。
- 探索一（人工分類）：
  - 疑問：50 題中三類各幾題？每題依據在教材哪一頁？
  - 操作：使用者逐題作答並查教材，記錄題號、正確答案、依據頁碼、類型、Ctrl+F 是否找得到。
  - 邊界：一份試題、一科教材；約一次完整讀題時間。
  - 完成條件：50 題都有分類與依據，或註明找不到。產出同時作為探索二的標準答案。
  - 紀錄表：[exploration-1-record](discovery/exploration-1-record.md)，由使用者本人填寫。
- 探索二（檢索比較）：
  - 疑問：依據在教材內的題目，關鍵字與向量檢索各能找回多少？
  - 操作：同一份切塊後的教材，兩種檢索各跑一次；判準在執行前寫下。
  - 邊界：只用探索一的那一科與那 50 題；embedding 模型與費用上限待定。
  - 完成條件：兩種方法的結果表，以及失敗題目的原因歸類。
- 並行探索（授權）：查教材 PDF 的版權頁與試題檔內的聲明；必要時向主辦單位詢問。不阻擋自用版本，阻擋公開。著作權法第 9 條關於考試試題的規定是否適用，尚未查證。
- 已授權內容／確認紀錄：使用者 2026-11-16 確認第一輪範圍與「先做自用版本」。同日確認科目與試題、探索一紀錄表進版控。
- 使用者 2026-11-16 表示之後會將 repo 轉為 public 供大家使用。這是之後的打算，本輪「暫時不做公開上線」不變。轉 public 時 repo 內只有程式、文件與紀錄表（題號、官方答案、頁碼、分類）；data/ 下的教材、試題與索引不在其中，能否再散布仍未確認。
