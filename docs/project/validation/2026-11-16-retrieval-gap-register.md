# 八題教材支持與檢索缺口清單

以原「題幹＋四選項」、k=5 為主基準。已確認存在核心教材依據但未進前五的組合是第 3 題向量、第 18 題 BM25、第 32 題向量。第 4、40 題的已審片段尚不足支持核心判準。第 49 題混合未中原預期頁，但已有其他核心支持，應列評估集合落差，不能當成核心檢索失敗。

同一題可同時有排名與完整解析的內容缺口。以下「內容不足」僅指已檢視頁面、片段及目前證據不足；尚未全面逐頁獨立複核雙科教材，不能推定全書沒有相關說明。情境映射也可能需要合理推論，不一定能靠新增引用消除。

## C．預期頁集合與支持範圍落差

- 第 4 題：三方法已找到原 expected 以外的公平性背景。原頁集合可能不完整，但新增這些頁仍只能給部分支持，不能修到通過就宣稱核心問題解決。
- 第 49 題混合：原 expected 的 S1:3-55:0 為第 7、S1:3-48:0 為第 12；前五已有 S1:3-62:0（第 1）、3-57:0（第 4）、3-57:1（第 5）核心支持。這是原頁集合未覆蓋替代依據，不是全無核心內容。
- 第 3 題向量：原頁碼命中，但只有概述，真正核心塊在第 16。頁集合既可能漏算有效內容，也可能把不足內容算命中。

本輪不修訂 expected。若未來修訂，另建版本、逐項記支持範圍及理由，保留原 v1 與 v2.0。

## 建議處理順序

1. 先處理第 28 題 MAE 外部補證：範圍小，使用者已確認需求，可驗證引用是否真正補上定義與適用性；先建立獨立來源筆記，再決定是否納入知識庫。
2. 第 4、40 題先確認核心內容缺口與補證範圍。這兩題優先補證，比只調整已知背景頁排名更直接。
3. 排序改善以第 3、18、32 題為既有診斷案例；正式選規則前補入獨立案例，避免只對八題挑有效做法。第 49 題先處理評估解讀，不以其原頁碼未中作單一最佳化目標。

同頁整塊去重未獲整體採用依據；完整包含規則在本批零觸發；只用題幹則三方法退步。以上結果支持保留現有完整查詢，並收斂後續實驗，不代表正式檢索已完成品質驗收。
