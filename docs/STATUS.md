# 目前狀態

- **階段**：可自用與展示的本機原型；管線不綁定領域，附 iPAS 範例（[examples/ipas](../examples/ipas/README.md)）。
- **repo 可見性**：Public（2026-11-18 由作者公開；公開前準備見下方）。
- **授權**：程式與作者自寫內容採 [MIT](../LICENSE)（2026-11-18）；教材、模型、維基內容各有不同權利條件，見 [THIRD_PARTY_NOTICES](../THIRD_PARTY_NOTICES.md)。
- **已經能做的**：iPAS 五科教材與一般文字型 PDF 的官方下載核對（`fetch`）與版本化索引、領域 profile、BM25／向量／混合檢索、PostgreSQL＋pgvector、本機 vLLM 生成、逐句引用與核對、AnythingLLM 聊天介面、PDF 原頁連結、多知識庫路由。
- **驗證方式**：`uv run pytest` 與 `uv run python -m ipas_hub.demo`；GitHub Actions CI 另跑 pgvector 整合測試、容器測試與啟動檢查。主張與測試的對照見 [EVIDENCE](EVIDENCE.md)。
- **評估結果**：243 題保留官方試題，混合 87.2%、向量 84.0%、BM25 81.9%；混合對 BM25 +5.3 個百分點（95% CI +1.7 ~ +9.0）。修正試題切題後補跑 23 題，合計 248 題：混合 87.9%、向量 83.5%、BM25 82.3%（+5.6，CI +2.4 ~ +9.7）。見 [評估](evaluation.md#保留題評估2026-11-18)。
- **理由與引用抽樣**：混合答對題抽 20 題人工判讀，理由正確 20、引用完全支持 18、部分支持 2。
- **尚未證明的**：大規模的理由與引用語意正確性（只有 20 題抽樣，作者本人判讀）；其他模型或其他領域上的結果；乾淨新機從零完整安裝（作者電腦重新 clone 走過手冊第 1–5、7 步，但沿用既有快取，見[操作手冊](setup.md#8-下次啟動停止與排錯)）；多人服務。

## 已知限制

- 只支援可擷取文字的 PDF；沒有 OCR、表格或圖片理解。
- 非 iPAS 領域的回答品質未另外驗證；部分固定訊息（例如「教材與外部搜尋都沒有取得依據」）仍使用「教材」一詞。
- 外搜的搜尋詞規劃提示以機器學習術語為例，其他領域的外搜品質未驗證。
- 聊天是單輪：只取最後一則使用者訊息；SSE 在完整生成後才傳送。
- 字詞核對與模型逐句核對都只是提示，不是事實查核；模型核對在合成負例上約三成會放過，且每題多一次模型呼叫。
